# 🤖 Projetos de IA Conversacional (Copilot Studio)

Este repositório reúne uma coleção de **Agentes Virtuais de Inteligência Artificial Conversacional** desenvolvidos utilizando o **Microsoft Copilot Studio** e integrados ao ecossistema **Power Platform / Low-Code**.

---

## 📂 Agentes Disponíveis no Repositório

### 🤖 1. Pietra
* **Descrição:** Agente focado em suporte e atendimento inteligente.
* **Recursos:**
  * Base de conhecimento personalizada integrada em Markdown (`.md`).
  * Fluxo de diálogos para resolução de dúvidas e triagem.
* **Tecnologias:** Copilot Studio, Generative Answers / RAG.

---

### 💳 2. EmprestAI
* **Descrição:** Agente conversacional especializado na simulação e automação de solicitações de empréstimos.
* **Recursos:**
  * Coleta e validação de dados do utilizador durante a conversa.
  * Lógica de tópicos e variáveis para direcionamento do atendimento.
* **Tecnologias:** Copilot Studio, Power Automate.

---

### 📅 3. ReservaFacil
* **Descrição:** Assistente virtual voltado para o agendamento e reserva de recursos/espaços.
* **Recursos:**
  * Fluxos estruturados para confirmação de disponibilidade e registro.
* **Tecnologias:** Copilot Studio, Power Apps / Dataverse.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Microsoft Copilot Studio** (Criação de tópicos, entidades e variáveis)
* **Power Automate / Power Platform** (Automação de fluxos e integrações)
* **Markdown / RAG** (Estruturação de bases de conhecimento para IA)
* **Git & GitHub** (Controlo de versão dos artefactos do projeto)

---

## 🚀 Como Explorar os Projetos

1. Navegue até a pasta do agente desejado (`/Pietra`, `/EmprestAI` ou `/ReservaFacil`) para examinar as bases de conhecimento e configurações.
2. Os ficheiros de conhecimento (`/knowledge`) contêm as bases de dados e documentos que alimentam as respostas gerativas dos robôs.
